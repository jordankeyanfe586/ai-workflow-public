# Préparation GitHub

Nom proposé : `ai-workflow`.

Description anglaise : Personal AI-assisted software development workflow with Claude Code, Codex, Git safeguards, independent reviews, and human oversight.

La copie n'hérite d'aucun historique Git privé. Aucun commit, remote ni dépôt distant n'est créé pendant la préparation. Le premier commit devra être réel et daté de son exécution, après validation humaine. Son message pourra être « Initial public release of AI-Workflow » conformément au choix de l'utilisateur.

L'identité Git effective actuelle utilise une adresse personnelle : ne pas l'imprimer ni l'hériter sans consentement. Avant git init/commit, choisir et valider une adresse GitHub noreply exacte depuis le compte GitHub ; ne pas inventer son identifiant numérique. Aucune identité globale n'est modifiée.

La licence MIT a été validée et appliquée. Éventuels changements de protections, commit, création distante, push et visibilité restent des décisions distinctes. Ne pas publier tant que le contenu final n'a pas été recontrôlé.
